ФАЙЛЫ ДЛЯ СДАЧИ

Отчёт_Орлов_Сергей_681_вариант_5_итоговый.docx — постановка задачи,
численный метод, описание реализации и результаты расчётов на IBM Polus.

solver_seq.c — исходный код последовательной программы.
solver_omp.c — исходный код параллельной программы с OpenMP.
polus_compile.sh — сборка обеих программ компилятором GCC с оптимизацией -O3.
polus_job.sh — запуск одной конфигурации с заданным числом повторов;
сохранение журналов, времён и решения первого повтора.
polus_suite_v2.sh — запуск серии конфигураций внутри задания LSF:
короткая проверка (check 1) или полный эксперимент (full 5).

Дополнительные скрипты:
collect_results.py — формирование сводных таблиц по результатам запусков.
compare_results.py — сравнение сохранённых последовательных и OpenMP-решений.

СБОРКА И ЗАПУСК НА IBM POLUS

Все файлы следует разместить в одной папке. Из этой папки выполнить:

    bash polus_compile.sh
    mkdir -p logs

Короткая проверка — шесть запусков:

    bsub -J v5_check -q short -W 00:15 -n 5 -R 'span[hosts=1]' -o 'logs/check.%J.out' -e 'logs/check.%J.err' bash ./polus_suite_v2.sh check 1

Полный эксперимент — 16 конфигураций по 5 повторов, всего 80 запусков:

    bsub -J v5_full -q normal -W 02:30 -n 5 -R 'span[hosts=1]' -o 'logs/full.%J.out' -e 'logs/full.%J.err' bash ./polus_suite_v2.sh full 5

Параметр -W задаёт предельное время задания. Состояние проверяется командой
bjobs. Результаты полной серии сохраняются в results/v2_full_НОМЕР_ЗАДАНИЯ/.
После успешного завершения в журнале появляется COMPLETE 80/80.
Расчётные программы запускаются через LSF, а не на входном узле.

Для получения таблиц и сравнения решений (требуется Python 3):

    python3 collect_results.py results/v2_full_НОМЕР_ЗАДАНИЯ
    python3 compare_results.py results/v2_full_НОМЕР_ЗАДАНИЯ

ПРИМЕЧАНИЯ

Время измеряется внутри программ и включает только итерационный решатель.
Построение системы, выделение памяти и запись решения в него не входят.
В итоговые таблицы заносится минимальное время из пяти повторов.

Пять слотов запрашиваются для максимальных 32 OpenMP-потоков по инструкции
Polus: M = floor(N/8) + 1, где N — число потоков, M — запрашиваемые ядра.
Источник: https://hpc.cs.msu.ru/node/254

MPI и гибридная MPI/OpenMP-реализация в данный комплект не входят.
